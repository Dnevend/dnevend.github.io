# 斯多葛打印机

我书桌上现在多了一台热敏打印机。闲鱼上淘的，XPrinter XP-80T，八十毫米纸宽，六十五块钱，包邮。每天早上九点，它自己醒过来，吐出一张英语学习小票。

票子上印着一篇斯多葛短文，英文原文，中文译文，挑出来的几个生词，配一张封面图。印完以后，电脑再用语音合成把英文念一遍，推到我的 Telegram 上。

这个事从头到尾是我指挥 AI 做出来的。写这篇文章，是想记下它怎么转起来，中间卡在哪。

<!-- truncate -->

## 为什么是一台打印机

两个念头凑到了一起。

一个念头是，我想让 AI 进到生活里来。过去它一直待在聊天窗口里，我找它，它才干活。我想要点反过来的东西：它自己到点干活，把结果递到我手里，不用我打开任何东西。

另一个念头是学英语。屏幕上的英文我划一下就没了，纸不一样，纸可以拿在手里画，可以贴冰箱上，可以第二天还在。Daily Stoic 这种每天一篇的短文，一篇几百个词，正好够一张小票的肚子。

热敏打印机还特别省事：不用墨盒，不用驱动，往局域网一挂，直接发字节过去就能印。

## 它每天在干什么

早上九点，定时任务把它叫醒。整条流程是这样的：

1. 去 dailystoic.com 的 sitemap 里翻出最新那篇，抓正文。
2. 把文章里的推广段落剔掉。
3. 翻译成中文。
4. 按词频表挑出几个生词，配上词典释义和原文例句。
5. 找一张相关的图当封面，转成黑白点阵。
6. 把这一切排成四十八列宽的小票，发到打印机。
7. 用 edge-tts 合成英文语音，推送到 Telegram。

有一件事我想单独说：**这套流程里，生成内容的每一步都没用大模型。** 翻译走一个免费接口，生词按词频表加词典挑，配图去图库搜。大模型用在了写这个程序上，程序每天跑起来的时候用不到它。这挺好，跑一次几乎不花钱，也不会哪天突然改输出格式。

打出来的小票长这样：

![打出来的英语小票](./receipt.png)

节选一段原文：

```text
Think about how rarely we give ourselves fully
to whatever we're doing. Working, some part of
us is thinking about the errands we need to run
later or the conversation we had the other day.
```

生词那一栏，机器挑出来的是 errands（差使）、inaccessible（难接近的）、sphere（范围）……每个词后面跟一句它自己出现的原文。比背单词表有意思，因为你知道它是从哪篇文章里长出来的。

## 我是怎么让 AI 把它做出来的

我没有自己一行行写。我当的是包工头。

分工大概是这样的：

- **小龙虾（OpenClaw）当调度**。我把一个任务写成简报，写清楚要什么、边界在哪、别碰什么。
- **OpenCode 的 worker 去干活**。每个任务单独开一个工作区，改完了由另一个家族的模型来挑刺，通过了才合并。
- **我负责定方向、验货、拍板**。换音色的时候，我让 AI 生成几段试听，我自己听，我自己选。打印机到了，真机联调也是我在中间传话。

写代码的活我确实没怎么干，但「要什么」这件事一直是我在说。AI 干得再快，它不知道我想要的是每天早上九点吐一张纸，而不是一个更好看的网页。

## 卡在哪

真正卡住我的，都不是什么高深问题，全是又小又气人的那种。

**一个字母写成了大写。** 封面图打出来是一长条乱码，中间还平白切了一刀纸。我第一反应是这打印机固件有毛病，还把配图功能关了，绕了两天。最后发现，是我这边把打印位图的命令头写错了，`GS v` 写成了 `GS V`——一个大写，意思就从「打图片」变成了「切纸」。打印机没毛病，它忠实地执行了一条错命令。我怪错了对象，白白耽误两天。

**定时任务一跑就报「No route to host」。** 手动跑好好的，挂到系统的定时任务里就连接不上打印机。折腾半天才明白，macOS 的「本地网络」权限把后台进程访问局域网的请求给拦了。最后改让程序在连不上时退回用系统自带的 nc 去发，才绕过去。

**源站停更了。** 一开始走它的 RSS 和接口抓，结果那个接口停在 2023 年就不动了，分类页还是 JavaScript 渲染的。只好改成去解析 sitemap，翻最新一篇。后来有几天它干脆没更新，我的打印机连着三天印了同一篇文章，浪费了三张纸。这才给它加了个台账：同一篇不重印，断更了就提醒我一句，别闷头印。

**系统的默认语音太难听。** 一开始用 macOS 自带的 say 念，机械得像在报站名。后来换成 edge-tts，挑了个听起来顺耳的女声，语速调慢一点，才像个人在念文章。

## 用了几天

它现在每天早上九点，准时把一张纸递到我面前。

老实说，机翻的质量一般，偶尔翻得挺离谱。那篇讲戴高乐的文章里有一句，意思是「每个角色在它自己的位置上都是第一位的」，机翻给的是「每个人都是自己领域的第一人」。意思跑了。可就是这种错，反倒让我停下来对照原文，把那个句子嚼了几遍。

这大概就是我想要的效果了。我没指望它给我多漂亮的译文，我要的是它每天把我按在椅子上，读一段英文，查两个词，想一分钟。纸做到了聊天窗口没做到的事。
